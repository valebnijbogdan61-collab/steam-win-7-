# Steam (Windows 7 edition)

Приватний лаунчер у стилі Steam для Windows 7. Ігри з itch.io через API-ключ.
Чистий C++ (Win32 + GDI + WinHTTP), без сторонніх бібліотек.
`.exe` (32-біт, працює на 32 і 64-бітній Win7) збирається на GitHub, локально нічого ставити не треба.

## Як отримати Steam.exe
1. Створи **приватний** репозиторій і залий туди вміст цього архіву.
2. Вкладка Actions -> Build Steam.exe -> Run workflow (або просто зроби push).
3. Коли збірка зелена, відкрий її і внизу в Artifacts скачай `Steam-Win7`.
   Усередині `Steam.exe` і `config.ini` (ключ уже там). Поклади їх в одну папку і запускай.

Якщо збірка червона, відкрий лог кроку Build і скинь помилку Claude.

## Важливо
- API-ключ itch.io лежить прямо в `config.ini` у корені репозиторію. Тримай репо **приватним**.
  Якщо зміниш ключ, відредагуй цей файл.
- На Windows 7 для HTTPS (TLS 1.2) потрібен SP1 + оновлення KB3140245
  (і ключ реєстру `DefaultSecureProtocols`). Без цього `api.itch.io` не відкриється.
- Іконка `resources/steam.ico` тимчасова, підміни файл і запуш.

## Структура
```
.github/workflows/build.yml   збірка на GitHub
config.ini                    API-ключ itch.io
resources/                    іконка, manifest, .rc
src/main.cpp                  вікно, навігація, вкладки
src/ui.*                      малювання (GDI), шрифти, градієнти
src/theme.h                   кольори
src/http.*                    WinHTTP: GET + завантаження файлів з прогресом
src/itch.*                    клієнт API itch.io (профіль, бібліотека, пошук, завантаження)
src/json.*, src/img.*         JSON-парсер, декодування обкладинок (GDI+)
src/config.*                  читання config.ini
src/zip.*                     розпакування .zip (Shell COM) і пошук головного .exe
src/sha256.*, src/account.*   локальний акаунт лаунчера (нік + хеш пароля, без мережі)
docs/DESIGN.md                опис інтерфейсу
```
